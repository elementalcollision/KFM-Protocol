# KFM-AE PostgreSQL Schema Documentation\n\nThis document describes the PostgreSQL schema used for the core agent registry and state tracking in the KFM-Agentic Evolution (KFM-AE) system. For relationship tracking, see the Neo4j schema documentation.\n\n**Target Database:** PostgreSQL 14+\n\n## ENUM Types\n\n### `lifecycle_state_enum`\n\nDefines the valid lifecycle states for an agent, based on PRD section 3.3.\n\n```sql\nCREATE TYPE lifecycle_state_enum AS ENUM (\n    \'NEW\',\n    \'EXPERIMENTAL\',\n    \'CANDIDATE\',\n    \'STABLE\',\n    \'DEPRECATED\',\n    \'ARCHIVED\',\n    \'KILLED\'\n);\n```\n\n## Tables\n\n### `Agents`\n\nStores the core information about each managed agentic entity.\n\n```sql\nCREATE TABLE Agents (\n    unique_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n    type VARCHAR(255) NOT NULL,\n    version VARCHAR(255) NOT NULL,\n    owner VARCHAR(255),\n    maintainer VARCHAR(255),\n    lifecycle_state lifecycle_state_enum NOT NULL DEFAULT \'NEW\',\n    creation_timestamp TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,\n\n    CONSTRAINT chk_version_not_empty CHECK (version <> \'\'),\n    CONSTRAINT chk_type_not_empty CHECK (type <> \'\')\n);\n```\n\n**Columns:**\n\n*   `unique_id` (UUID, PK): Unique identifier for the agent. Uses `gen_random_uuid()` which requires the `pgcrypto` extension.\n*   `type` (VARCHAR(255), NOT NULL): Type of the agent (e.g., \'Software Artifact\', \'AI Model\'). Refers to PRD section 3.1.\n*   `version` (VARCHAR(255), NOT NULL): Version identifier (e.g., semantic version, git hash).\n*   `owner` (VARCHAR(255), NULL): Identifier for the responsible owner/team.\n*   `maintainer` (VARCHAR(255), NULL): Identifier for the specific maintainer/contact.\n*   `lifecycle_state` (lifecycle\_state\_enum, NOT NULL, DEFAULT \'NEW\'): Current KFM lifecycle state.\n*   `creation_timestamp` (TIMESTAMPTZ, NOT NULL, DEFAULT CURRENT\_TIMESTAMP): Timestamp of agent record creation.\n\n**Constraints:**\n\n*   `chk_version_not_empty`: Ensures `version` is not an empty string.\n*   `chk_type_not_empty`: Ensures `type` is not an empty string.\n\n### `AgentMetadata`\n\nStores flexible key-value metadata associated with agents.\n\n```sql\nCREATE TABLE AgentMetadata (\n    id BIGSERIAL PRIMARY KEY,\n    agent_id UUID NOT NULL,\n    key VARCHAR(255) NOT NULL,\n    value JSONB,\n    value_type VARCHAR(50),\n\n    CONSTRAINT fk_agent\n        FOREIGN KEY(agent_id)\n        REFERENCES Agents(unique_id)\n        ON DELETE CASCADE,\n\n    CONSTRAINT unique_agent_key UNIQUE (agent_id, key)\n);\n```\n\n**Columns:**\n\n*   `id` (BIGSERIAL, PK): Surrogate primary key for the metadata entry.\n*   `agent_id` (UUID, NOT NULL): Foreign key referencing `Agents.unique_id`.\n*   `key` (VARCHAR(255), NOT NULL): The name (key) of the metadata attribute.\n*   `value` (JSONB, NULL): The value of the metadata attribute.\n*   `value_type` (VARCHAR(50), NULL): Optional type hint for the value (e.g., \'string\', \'number\', \'json\').\n\n**Constraints:**\n\n*   `fk_agent`: Ensures referential integrity with `Agents`. Deletes metadata if the parent agent is deleted (ON DELETE CASCADE).\n*   `unique_agent_key`: Ensures each metadata key is unique per agent.\n\n### `StateTransitionLog`\n\nRecords the history of lifecycle state changes for agents.\n\n```sql\nCREATE TABLE StateTransitionLog (\n    id BIGSERIAL PRIMARY KEY,\n    agent_id UUID NOT NULL,\n    previous_state lifecycle_state_enum,\n    new_state lifecycle_state_enum NOT NULL,\n    transition_timestamp TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    triggering_agent_id UUID,\n    triggering_user_id VARCHAR(255),\n    justification TEXT,\n\n    CONSTRAINT fk_log_agent\n        FOREIGN KEY(agent_id)\n        REFERENCES Agents(unique_id)\n        ON DELETE CASCADE\n);\n```\n\n**Columns:**\n\n*   `id` (BIGSERIAL, PK): Surrogate primary key for the log entry.\n*   `agent_id` (UUID, NOT NULL): Foreign key referencing `Agents.unique_id`.\n*   `previous_state` (lifecycle\_state\_enum, NULL): State before transition (NULL for initial creation).\n*   `new_state` (lifecycle\_state\_enum, NOT NULL): State after transition.\n*   `transition_timestamp` (TIMESTAMPTZ, NOT NULL, DEFAULT CURRENT\_TIMESTAMP): Timestamp of transition.\n*   `triggering_agent_id` (UUID, NULL): Optional: Agent ID initiating change.\n*   `triggering_user_id` (VARCHAR(255), NULL): Optional: User ID initiating change.\n*   `justification` (TEXT, NULL): Reason/policy for state transition.\n\n**Constraints:**\n\n*   `fk_log_agent`: Ensures log entries link to a valid agent. Deletes logs if the agent is deleted (ON DELETE CASCADE).\n\n## Triggers\n\n### `agents_state_change_trigger` on `Agents`\n\nAutomatically logs state changes to the `StateTransitionLog` table whenever an agent is inserted or its `lifecycle_state` is updated.\n\n*   **Event:** `AFTER INSERT OR UPDATE`\n*   **Function:** `log_agent_state_change()`\n\n**Trigger Function Logic (`log_agent_state_change()`):**\n\n*   Runs after an insert or update on the `Agents` table.\n*   If the operation is an UPDATE, it checks if `lifecycle_state` has changed.\n*   If the state changed (or if it\'s an INSERT), it inserts a record into `StateTransitionLog`.\n*   It attempts to retrieve `triggering_agent_id`, `triggering_user_id`, and `justification` from PostgreSQL session variables (`myapp.*` namespace) set by the application *before* the `Agents` table modification. If variables are not set, defaults are used.\n\n## Indexes\n\n### `Agents` Table\n\n*   `idx_agents_type`: On `type`. Supports filtering by agent type.\n*   `idx_agents_lifecycle_state`: On `lifecycle_state`. Supports filtering by state.\n*   `idx_agents_owner`: On `owner`. Supports filtering by owner.\n*   `idx_agents_active_states`: Partial index on `lifecycle_state` WHERE state NOT IN (\'ARCHIVED\', \'KILLED\'). Supports finding non-terminal agents.\n\n### `AgentMetadata` Table\n\n*   `idx_agentmetadata_agent_id`: On `agent_id`. Supports finding metadata for a specific agent.\n*   `idx_agentmetadata_key`: On `key`. Supports finding specific keys across agents.\n*   `idx_agentmetadata_value_gin`: GIN index on `value` (JSONB). Supports querying within the JSONB value.\n\n### `StateTransitionLog` Table\n\n*   `idx_log_agent_id`: On `agent_id`. Supports retrieving history for a specific agent.\n*   `idx_log_transition_timestamp`: On `transition_timestamp`. Supports time-based history queries.\n```
