# Design & Implementation Notes

## Resource Types
- CPU, Memory, Ephemeral Storage (GPU optional later)

## State-Based Allocation Logic

| State          | Resource Action                                          | Rationale                                                                         | K8s Implementation Idea                                                                         |
| :------------- | :------------------------------------------------------- | :-------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------- |
| `NEW`          | Allocate Minimal                                         | Initialization/setup needs                                                        | Low `requests`/`limits` in base Pod template                                                |
| `EXPERIMENTAL` | Allocate Moderate (Quota Controlled)                     | Active dev/testing within limits                                                   | Moderate `requests`/`limits`. Use namespace `ResourceQuota`                                    |
| `CANDIDATE`    | Allocate Higher (Closer to Production)                   | Final testing/validation needs                                                  | Increase `requests`/`limits` towards STABLE levels                                          |
| `STABLE`       | Allocate Production (Quota Controlled, Highest Priority) | Critical, needs guaranteed resources                                             | Highest `requests`/`limits`. Use `ResourceQuota` & `PriorityClass`                             |
| `DEPRECATED`   | Decrease/Maintain Moderate (Notification Sent)           | Phasing out, reduce footprint, notify dependents                                  | Lower `requests`/`limits`. Trigger notifications via KFM event system                           |
| `ARCHIVED`     | Reclaim Compute Resources (Data Persists)                | Stop compute, persist data (logs, etc.)                                        | Set `replicas: 0`. Retain PVCs. Trigger archival process                                    |
| `KILLED`       | Reclaim All Resources (Data Purged)                      | Complete removal                                                               | Delete Deployment/StatefulSet, Service, PVCs, ConfigMaps, Secrets. Trigger data purge      |

## Implementation Ideas
- Use standard K8s `resources.requests` and `resources.limits`
- Resource Management Service listens for agent state changes (via KFM events or polling Agent Registry)
- On state change, service updates K8s Deployment/StatefulSet (`replicas`, `resources.requests`/`limits`) or deletes resources
- Consider a dedicated Kubernetes Operator watching Agent CRDs for managing associated resources based on state

```

### Quota Enforcement Architecture

Implement a three-tier enforcement system:
1. **Application Layer**: Pre-validation before resource allocation requests
2. **Service Layer**: Enforcement during resource creation/update operations
3. **Infrastructure Layer**: Kubernetes ResourceQuota objects as a final safety mechanism

### Quota Calculation Logic

```java
public class QuotaCalculator {
  /**
   * Calculates if requested resources are within quota limits
   * @param state Lifecycle state of the agent
   * @param requestedResources Map of resource types to requested amounts
   * @return ValidationResult with approval status and reason if rejected
   */
  public ValidationResult validateAgainstQuota(
      LifecycleState state, 
      Map<ResourceType, Quantity> requestedResources) {
    
    // Get quotas for the specific state
    Map<ResourceType, Quota> stateQuotas = quotaRepository.getQuotasForState(state);
    
    // Fall back to defaults if specific quotas not defined
    if (stateQuotas.isEmpty()) {
      stateQuotas = quotaRepository.getDefaultQuotas();
    }
    
    // Check each resource against its quota
    for (Map.Entry<ResourceType, Quantity> entry : requestedResources.entrySet()) {
      ResourceType type = entry.getKey();
      Quantity requested = entry.getValue();
      
      if (!stateQuotas.containsKey(type)) {
        continue; // No quota defined for this resource type
      }
      
      Quota quota = stateQuotas.get(type);
      if (requested.compareTo(quota.getLimit()) > 0) {
        return ValidationResult.rejected(
            String.format("Requested %s exceeds quota limit of %s for state %s", 
                          requested, quota.getLimit(), state));
      }
    }
    
    return ValidationResult.approved();
  }
}
```

# Example implementation for Kubernetes adapter

class KubernetesAdapter:
    def __init__(self, config_file=None, context=None):
        from kubernetes import client, config
        
        if config_file:
            config.load_kube_config(config_file=config_file, context=context)
        else:
            # In-cluster configuration
            config.load_incluster_config()
            
        self.apps_v1 = client.AppsV1Api()
        self.core_v1 = client.CoreV1Api()
        self.custom_objects = client.CustomObjectsApi()
        
    async def scale_deployment(self, name, namespace, replicas):
        """Scale a deployment to the specified number of replicas"""
        try:
            # Patch operation
            patch = {"spec": {"replicas": replicas}}
            return self.apps_v1.patch_namespaced_deployment(
                name=name,
                namespace=namespace,
                body=patch
            )
        except client.exceptions.ApiException as e:
            if e.status == 404:
                raise ResourceNotFoundException(f"Deployment {name} not found")
            elif e.status == 409:
                # Handle conflict with retry logic
                await self._retry_with_backoff(lambda: self.scale_deployment(name, namespace, replicas))
            else:
                raise InfrastructureProvisioningException(f"Failed to scale deployment: {str(e)}")
                
    async def update_resource_limits(self, name, namespace, container_name, cpu_limit, memory_limit):
        """Update resource limits for a specific container in a deployment"""
        try:
            # Get current deployment
            deployment = self.apps_v1.read_namespaced_deployment(name, namespace)
            
            # Find the container and update its resources
            for container in deployment.spec.template.spec.containers:
                if container.name == container_name:
                    container.resources.limits = {
                        "cpu": cpu_limit,
                        "memory": memory_limit
                    }
                    
            # Update the deployment
            return self.apps_v1.replace_namespaced_deployment(
                name=name,
                namespace=namespace,
                body=deployment
            )
        except client.exceptions.ApiException as e:
            # Handle exceptions with appropriate error types
            raise InfrastructureProvisioningException(f"Failed to update resources: {str(e)}")
            
    async def _retry_with_backoff(self, operation, max_retries=3, base_delay=1):
        """Retry an operation with exponential backoff"""
        import asyncio
        
        for attempt in range(max_retries):
            try:
                return await operation()
            except Exception as e:
                if attempt == max_retries - 1:
                    raise
                delay = base_delay * (2 ** attempt)
                await asyncio.sleep(delay)
```

```python
async def provision_resources(self, resource_spec):
    """Provision resources according to specification with rollback capability"""
    created_resources = []
    try:
        # Create resources in order
        for resource in resource_spec:
            result = await self._create_resource(resource)
            created_resources.append({"resource": result, "spec": resource})
        return created_resources
    except Exception as e:
        # Rollback in reverse order
        for resource in reversed(created_resources):
            await self._delete_resource(resource["resource"])
        raise
```
